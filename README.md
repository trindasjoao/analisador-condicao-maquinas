# analisador-condicao-maquinas
Trabalho de Algoritmos e Programação de Computadores feito por alunos de Engenharia Mecânica do primeiro período. O código busca ler medições de uma máquina, armazenar dinamicamente todas as amostras, classificar a condição da operação, calcular estatísticas e produzir o relatório em arquivo.
